# GameShow · 作品展示分享平台（本地版）

一个可以在你自己电脑上运行的游戏 / 软件作品展示分享网站。任何人都能注册账号、发布自己的作品（名称、介绍、分类、封面、截图、演示视频），访客可以浏览、搜索、查看详情。

## 立即使用

网站服务**现在正在运行**，直接用浏览器打开：

```
http://localhost:3000
```

注册一个账号，就可以上传你的第一个作品了。

## 如何启动 / 停止

```bash
# 启动（在项目根目录执行）
npm start

# 停止：在运行窗口按 Ctrl + C，或在任务管理器中结束 node.exe
```

> 数据会持久化保存在本地，重启服务后账号和作品都还在。

## 功能清单

- **用户系统**：注册 / 登录（JWT，密码加密存储）
- **首页**：作品卡片网格、9 大分类筛选、关键词搜索、分页
- **作品详情页**：封面、分类、作者、浏览量、简介、截图预览、演示视频播放
- **上传 / 编辑**：发布或修改作品，支持本地上传图片视频（也可粘贴网络地址）
- **我的作品**：登录后管理自己发布的作品（查看 / 编辑 / 删除）
- **权限控制**：写操作需要登录，且只能修改 / 删除自己的作品

## 技术栈

- 后端：Node.js + Express + SQLite（better-sqlite3，零配置免安装数据库）
- 前端：React 18 + React Router + Vite（构建后由后端统一托管）
- 认证：JWT + bcryptjs
- 上传：Multer 本地存储到 `uploads/` 目录

## 目录结构

```
作品展示平台/
├── server/          # 后端代码
│   ├── index.js     # 服务入口
│   ├── db.js        # SQLite 数据库初始化
│   ├── auth.js      # 登录鉴权
│   └── routes/      # 认证 / 作品 API
├── client/          # 前端代码（React）
│   └── src/
│       ├── pages/   # 各页面
│       └── components/
├── scripts/         # 工具脚本（e2e 测试、数据清理）
├── uploads/         # 上传的图片 / 视频文件
├── data/            # SQLite 数据库文件（gameshow.db）
└── dist/            # 前端构建产物
```

## 常见问题

- **想换端口**：设置环境变量 `PORT`，如 `set PORT=8080 && npm start`
- **想改登录密钥**：设置环境变量 `JWT_SECRET`
- **上传文件保存在哪**：`uploads/` 目录
- **数据库文件在哪**：`data/gameshow.db`
